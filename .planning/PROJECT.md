# Project Vision & Scope: Portfolio Website

## Project Vision
A premium, highly interactive developer portfolio that showcases advanced capabilities in Data Science, AI Engineering, and Full-Stack Development. It includes a custom back-office administrative panel to manage projects, blogs, credentials, and expertise.

## Target Audience
- Tech recruiters and engineering managers looking for senior developer/architect talent.
- Potential freelance or contract clients looking for high-end technical design and execution.

## Core Pillars
1. **Premium Aesthetic & UX**: Grounded in curated style guides, rich micro-animations, glassmorphism, responsive grids, dark mode, and state-of-the-art interactive layouts.
2. **Robust Backoffice**: Content managed dynamically via a protected Supabase backend admin dashboard.
3. **Optimized Performance**: Built with Next.js, optimized images, minimal hydration overhead, and clean CSS styling.

## Milestones Overview
- **v1.0 - Core Infrastructure & Admin Control**: Supabase DB, Auth, Admin CRUD. (Completed)
- **v2.0 - Premium UI Revamp (Landing Page Focus)**: Re-imagining the homepage with world-class UX/UI, senior-level copy, high-fidelity components, and Refero design alignment. (Completed)
- **v3.0 - Public Pages & Detail Experiences**: Extending the v2.0 premium design language to public sub-pages and detail/overlay experiences. Extended with Phase 04: end-to-end bilingual (TR/EN) i18n via next-intl (URL routing `/tr`+`/en` + bilingual DB `_en` columns). (Active)
