# Archived Requirements: Milestone v1.0

## Core Requirements
- **REQ-01: Database Setup**: Initialize Supabase database with projects, blogs, expertise, and profile schemas.
- **REQ-02: Authentication**: Establish secure admin login using Supabase Auth.
- **REQ-03: Dashboard & Layout**: Build an administrative interface to manage portfolio content.
- **REQ-04: Projects CRUD**: Admin should be able to create, read, update, and delete projects.
- **REQ-05: Blog CRUD**: Admin should be able to manage articles/posts.
- **REQ-06: Expertise Management**: Admin should be able to manage core capability cards.
