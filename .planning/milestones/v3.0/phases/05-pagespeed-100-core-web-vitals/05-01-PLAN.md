## Detaylı Görevler

### T1: Material Symbols Render-Blok Fontu Kaldır (REQ-PERF-01)
**Dosyalar:** `src/app/globals.css`, `src/components/*`, `src/app/admin/*`
**Durum:** `globals.css:1` harici `@import url("https://fonts.googleapis.com/...Material+Symbols+Outlined...")` → render-blok.

**Adımlar:**
1. `globals.css` satır 1 `@import`'u **sil**.
2. İkon stratejisi: public/admin tarafında `material-symbols-outlined` span'ları lucide-react inline SVG'ye taşınacak (öncelik public sayfalar; admin ikincil).
3. Kullanılan glyph'leri tespit et (`mail`, `location_on`, `workspace_premium`, `add`, `delete`, `visibility`, `code`, `open_in_new`, `arrow_outward` vb.) → lucide-react eşdeğerleri (`Mail`, `MapPin`, `Award`, `Plus`, `Trash2`, `Eye`, `Code`, `ExternalLink`, `ArrowUpRight`).
4. Eğer tam glyph gerekirse → `public/fonts/material-symbols.woff2` subset olarak self-host + `@font-face` (font-display: block, unicode-range subset) `globals.css`'e ekle.

**Doğrulama:** `grep -r "material-symbols" src/` → kalan referanslar yalnız self-host `@font-face` veya lucide ikonlar. CSS `@import url(googleapis)` sıfır.

### T2: next/font Optimizasyonu (REQ-PERF-01)
**Dosyalar:** `src/app/layout.tsx`
**Adımlar:**
1. `Inter` ve `Space_Grotesk` çağrılarına `display: "swap"`, `preload: true`, `adjustFontFallback: true` ekle.
2. Font değişkenleri korunsun (`--font-inter`, `--font-space-grotesk`).
3. `<head>`'a otomatik `<link rel="preload">` Next tarafından eklenir; ekstra manuel preload gerekmez.

**Doğrulama:** Build çıktısında font preload link'leri mevcut; FOUT minimal.

### T3: globals.css @import Temizliği (REQ-PERF-01)
**Dosyalar:** `src/app/globals.css`
**Adımlar:**
1. T1'de googleapis `@import` zaten silindi.
2. `@import "tw-animate-css"` → kullanım denetle; eğer animate utility'leri kullanılıyorsa koru (PostCSS resolve eder, harici ağ isteği değil), kullanılmıyorsa kaldır.
3. Kullanılmayan `@keyframes`/animation tanımlarını denetle (`blob`, `ripple`, `spin-around` vb.) — yalnız referanslananlar kalsın.

**Doğrulama:** `globals.css` harici `url()` isteği yok; CSS boyutu makul.

### T4: next/image Optimizasyonu (REQ-PERF-02)
**Dosyalar:** `src/components/HeroSection.tsx`, `src/app/page.tsx`, `src/components/ui/bento-grid.tsx`, `src/components/projects/ProjectDetailModal.tsx`, `src/components/projects/ProjectShowcaseCard.tsx`
**Adımlar:**
1. Tüm `Image` kullanımlarında `unoptimized` prop'unu **sil** → Next optimizer AVIF/WebP üretsin.
2. Hero portresi (LCP adayı): `priority` + `sizes="(max-width: 768px) 100vw, 360px"` ekle.
3. Proje kart görselleri: `sizes="(max-width: 768px) 100vw, (max-width: 1200px) 50vw, 33vw"`, `loading="lazy"` (default).
4. `fill` kullanılan yerlerde container'a sabit aspect/height olduğundan emin ol (CLS=0).
5. `next.config.mjs` `images.formats: ['image/avif','image/webp']` ekle (T11'de).

**Doğrulama:** `grep -r "unoptimized" src/` boş. Build sonrası `/.next/cache/images` dolu.

### T5: SSR → ISR (REQ-PERF-03)
**Dosyalar:** `src/app/page.tsx`, `src/app/projects/page.tsx`, `src/app/expertise/page.tsx`, `src/app/certificates/page.tsx`, `src/app/contact/page.tsx`
**Adımlar:**
1. `export const dynamic = "force-dynamic"` → **sil**. Yerine `export const revalidate = 300;` (5 dk ISR).
2. Supabase çağrılarına `fetchOptions: { cache: 'no-store' }` yoksa default ile önbellek; tercihen `next: { revalidate: 300 }` opsiyonu (Supabase client `select` 2. argümanı desteklemiyorsa route-level `revalidate` yeterli).
3. Admin sayfaları `dynamic = "force-dynamic"` korunsun (auth gerekli).

**Doğrulama:** Homepage 2. istekte önbellekten gelir (TTFB düşer). `next info` build çıktısında `/?` (ISR) işareti.

### T6: WebGL Mesh Gradient → CSS/SVG (REQ-PERF-04)
**Dosyalar:** `src/components/HeroSection.tsx`, `src/components/ui/static-mesh-gradient.tsx` (yeni içerik), `package.json`
**Adımlar:**
1. `HeroSection` `StaticMeshGradient` (shaders-react) kullanımını kaldır.
2. Yerine saf CSS çok-katmanlı radial/conic-gradient (Sunset paleti: teal/terra-cotta/orange/white) ile statik arka plan üret — `<div aria-hidden>` + Tailwind/CSS gradient katmanları.
3. `src/components/ui/static-mesh-gradient.tsx` → basit CSS-gradient bileşenine dönüştür (aynı export isimleri; presetleri koru ama params'ları CSS renklerine eşle). Eski `@paper-design/shaders-react` import'u kaldır.
4. `package.json`'dan `@paper-design/shaders` + `@paper-design/shaders-react` dependency'leri kaldır (T12'de npm uninstall).
5. `src/app/mesh-demo` rotası varsa basit CSS demo ile uyumla.

**Doğrulama:** `grep -r "@paper-design" src/` boş. Hero arka planı görsel olarak benzer premium ton korunmuş. Ana thread bloğu yok.

### T7: Zengin Metadata + html lang (REQ-SEO-01)
**Dosyalar:** `src/app/layout.tsx`, public sayfalar
**Adımlar:**
1. `metadataBase: new URL(process.env.NEXT_PUBLIC_SITE_URL || 'http://localhost:3000')`.
2. `metadata` nesnesine: `metadataBase`, `openGraph` (title/description/url/siteName/images/locale/type), `twitter` (card='summary_large_image'), `alternates.canonical`, `robots` (index/follow), `authors`, `creator`, `keywords`.
3. `<html lang="tr">`.
4. Her public sayfaya sayfa-bazı `metadata` (title/description/canonical).

**Doğrulama:** `view-source` `<head>` openGraph/twitter/canonical etiketleri mevcut.

### T8: sitemap.ts + robots.ts + manifest.ts + JSON-LD (REQ-SEO-02)
**Dosyalar (yeni):** `src/app/sitemap.ts`, `src/app/robots.ts`, `src/app/manifest.ts`, `src/app/layout.tsx` (JSON-LD)
**Adımlar:**
1. `sitemap.ts`: `default` export `MetadataRoute.Sitemap` — `/`, `/projects`, `/expertise`, `/certificates`, `/contact` (lastModified, changeFrequency, priority).
2. `robots.ts`: `default` export `MetadataRoute.Robots` — `rules: [{ userAgent: '*', allow: '/', disallow: ['/admin','/login','/auth'] }]`, `sitemap: ${siteUrl}/sitemap.xml`.
3. `manifest.ts`: `default` export `MetadataRoute.Manifest` — name/short_name/theme_color/background_color/icons (192/512).
4. `layout.tsx` JSON-LD `<script type="application/ld+json">` `Person` + `WebSite` (name, url, author).

**Doğrulama:** `/sitemap.xml`, `/robots.txt`, `/manifest.webmanifest` 200 döner; içerik geçerli.

### T9: public/ Varlıkları (REQ-SEO-03)
**Dosyalar (yeni):** `public/favicon.ico`, `public/icon.svg`, `public/apple-icon.png`, `public/og-image.png`, `public/mask-icon.svg`
**Adımlar:**
1. `public/` klasörü oluştur.
2. SVG tabanlı favicon + apple-touch icon (Champagne Gold "M" monogram). og-image 1200x630.
3. `src/app/icon.tsx`/`src/app/apple-icon.tsx` (ImageResponse) ile dinamik ikon üretimi — veya statik `public/` dosyaları.
4. metadata `icons` + `openGraph.images` bunlara referans versin.

**Doğrulama:** `/favicon.ico`, `/icon.svg`, `/og-image.png` 200; meta `og:image` set.

### T10: Erişilebilirlik (REQ-A11Y-01)
**Dosyalar:** tüm public + admin `*.tsx`, `globals.css`
**Adımlar:**
1. İkon-butonlara `aria-label` (admin delete/edit, header menü, dock ikonları).
2. Form inputlarına `<label htmlFor="id">` (ContactForm, login, admin formlar) — placeholder örnek, label ilişkisel.
3. Düşük kontrastlı `variant/80`, `mono [9px]` → en az `variant` (4.5:1) seviyesine çıkar; çok küçük `text-[9px]` → en az `text-xs`.
4. `globals.css`'e `@media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation-duration: .001ms !important; transition-duration: .001ms !important; } }`.
5. Skip-to-content linki (`<a href="#main" class="sr-only focus:not-sr-only">`), `<main id="main">` landmark.

**Doğrulama:** Lighthouse Accessibility denetimleri pass; axe-core sıfırlama.

### T11: CSP + HSTS + Cache Header'ları (REQ-BP-01)
**Dosyalar:** `next.config.mjs`
**Adımlar:**
1. `headers()` fonksiyonuna ekle: `Content-Security-Policy` (default-src 'self'; img-src 'self' data: blob: https://*.supabase.co https://lh3.googleusercontent.com https://images.unsplash.com; font-src 'self' data:; script-src 'self' 'unsafe-inline' 'unsafe-eval'; style-src 'self' 'unsafe-inline'; connect-src 'self' https://*.supabase.co).
2. `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload`.
3. `X-DNS-Prefetch-Control: on`.
4. Statik varlıklar için `_next/static` kaynağına ayrı header set → `Cache-Control: public, max-age=31536000, immutable`.
5. `images.formats: ['image/avif','image/webp']` ekle (T4 bağı).

**Doğrulama:** HTTP yanıt header'ları `curl -I` ile görülür; CSP raporu hatasız.

### T12: Bundle Dedup (REQ-PERF-04)
**Adımlar:**
1. `npm uninstall @paper-design/shaders @paper-design/shaders-react` (T6 bağı).
2. `framer-motion` vs `motion`: `magic-card.tsx` `motion/react` → hangi tek paketi tutacağımıza karar ver; kullanılmayanı `npm uninstall`. (Tercih: framer-motion koru, magic-card import'larını `framer-motion`'a çevir.)
3. İkon kütüphaneleri: lucide-react tercih; `@heroicons/react`/`@radix-ui/react-icons` kullanım alanlarını lucide'ye taşı, sonra uninstall (eğer yalnız bento/dock kullanıyorsa).
4. `npm run build` çıktısında First Load JS bundle makul (< 150KB public sayfalar hedef).

**Doğrulama:** `package.json` temiz; build bundle raporu düşük.
