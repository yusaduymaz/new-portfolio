# Plan: Statik UI Stringlerinin Çevirisi + Locale Switcher (Plan 04-02 — v3.0)

## Current Objective
Tüm hard-coded Türkçe UI stringlerini `useTranslations`/`getTranslations` ile çeviri anahtarlarına taşımak, `tr.json`/`en.json`'u eksiksiz doldurmak ve Header'a premium Locale Switcher eklemek. Bu plandan sonra **statik UI uçtan uca EN/TR çalışır**.

- [ ] 1. `tr.json`/`en.json` tüm kategorileri doldur (nav, hero, about, expertise, projects, certificates, contact, footer, form, common, meta).
- [ ] 2. `src/components/layout/Header.tsx`: navLinks + "Giriş Yap" → `t('nav.*')` (client `useTranslations('nav')`).
- [ ] 3. `src/components/layout/Footer.tsx`: uptime + "Tüm hakları saklıdır" → `t('footer.*')`.
- [ ] 4. `src/components/HeroSection.tsx`: "Çalışmalarımı İncele", "İletişime Geç", alt başlık → `t('hero.*')`.
- [ ] 5. `src/components/ExpertiseBento.tsx`: "Uzmanlık Alanları" + iki kutu açıklama → `t('expertise.*')`.
- [ ] 6. `src/components/ContactForm.tsx`: label/placeholder/"GÖNDER"/"GÖNDERİLİYOR" → `t('form.*')`.
- [ ] 7. `src/components/projects/*` (v3.0: ProjectShowcaseCard, ProjectDetailModal, ProjectsExplorer) VEYA `src/components/ui/bento-grid.tsx` (BentoCard) — aktif olan içindeki TR stringler ("Kullanılan Teknolojiler", "Canlı Demo", "Detayları Gör", empty-state) → `t('projects.*')`.
- [ ] 8. `[locale]/page.tsx`: Hakkımda, metrik etiketleri (Yıl Deneyim/Proje/Müşteri Memnuniyeti), "Seçilmiş Çalışmalar", "TÜM PROJELERİ GÖR", "PROJE BULUNAMADI", Bağlantı kartı metinleri → `getTranslations`.
- [ ] 9. `[locale]/expertise/page.tsx`, `projects/page.tsx`, `certificates/page.tsx`, `contact/page.tsx`: başlık + alt başlık + boş-durum metinleri → `getTranslations`.
- [ ] 10. `[locale]/layout.tsx` `generateMetadata`: `meta.title`/`meta.description` locale'a göre.
- [ ] 11. Locale Switcher (`src/components/layout/LocaleSwitcher.tsx`): glass segmented toggle TR|EN, `useLocale`+`useRouter`, altın aktif-state (SPEC §0 grounding); Header (desktop+mobile) içine yerleştir.
- [ ] 12. `contactActions.ts` toast mesajları EN/TR (server action locale-aware — header/cookie'den locale oku).
- [ ] 13. `npm run lint` + `npm run build`; grep TR-string denetimi; TR/EN UI UAT.

## Verification
- `grep` TR sabit string tarama → yalnızca DB'den gelen dinamik metin kalmalı.
- Header toggle TR↔EN: tüm görünen UI stringleri anında değişiyor.
- `/en` tüm rotalarda %100 İngilizce UI; `/tr` %100 Türkçe.
- Build + lint temiz.
