# Plan: i18n Altyapısı & Routing (Plan 04-01 — v3.0)

## Current Objective
next-intl kurulumu, `[locale]` segmentine public rotaların taşınması, middleware'in Supabase auth ile birleştirilmesi, çeviri dosya iskeleti ve `NextIntlClientProvider` + `<html lang>` entegrasyonu. **Bu planda henüz string çevirisi YAPILMAZ** (04-02).

## Tasks
- [ ] 1. `next-intl` paketini kur (`npm i next-intl`).
- [ ] 2. `src/i18n/routing.ts` oluştur: `locales:['tr','en']`, `defaultLocale:'tr'`, `pathnames` (public rotalar).
- [ ] 3. `src/i18n/request.ts` oluştur (server `getRequestConfig`, `src/messages/{locale}.json` yükler).
- [ ] 4. `src/messages/tr.json` + `en.json` iskelet (kategoriler + örnek anahtarlar; tam doldurma 04-02).
- [ ] 5. Public page'leri `src/app/[locale]/` altına taşı: `page.tsx`, `expertise/`, `projects/`, `certificates/`, `contact/`. `admin/`, `login`, `auth`, `contactActions.ts` yerinde kalır.
- [ ] 6. `src/app/layout.tsx` → `src/app/[locale]/layout.tsx`: `setRequestLocale`, `NextIntlClientProvider`, `<html lang={locale}>`, fontlar.
- [ ] 7. `generateStaticParams` ile `[{locale:'tr'},{locale:'en'}]`.
- [ ] 8. `src/middleware.ts`: next-intl `createMiddleware` + mevcut Supabase auth redirect tek `matcher`'da; admin/login auth akışı korunur.
- [ ] 9. Mevcut `<Link href>` / `redirect` / `usePathname` kullanımlarını `next-intl` `Link`/`usePathname` ile locale-aware yap.
- [ ] 10. `npm run lint` + `npm run build`; `localhost:3000/` → `/tr`, `/en` render doğrulaması.

## Verification
- `npm run build` temiz.
- `/` → `/tr` (default); `/en` render; her iki locale'da sayfa açılıyor.
- Admin/login rotaları hâlâ çalışıyor (auth redirect korunuyor).
- `<html lang>` locale'a göre değişiyor.
